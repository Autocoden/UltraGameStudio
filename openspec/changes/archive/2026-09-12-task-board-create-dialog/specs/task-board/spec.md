## ADDED Requirements

### Requirement: 新建任务弹窗

每个阶段列的列头必须提供新建入口（"+"按钮）；点击后弹出新建任务弹窗，且该列作为新卡片的初始阶段。弹窗必须包含：标题输入框（必填）、描述多行输入（可选）、以及四项可选分类下拉——分类（功能/缺陷修复/重构/文档/安全）、优先级（低/中/高/紧急）、复杂度（极低/小/中/大/复杂）、影响（低影响/中等影响/高影响/关键影响）。取消或按 Esc 关闭弹窗时不得创建任何卡片；提交后弹窗关闭，新卡片出现在触发列的末尾。标题为空白（仅空白字符）时提交必须被拒绝且弹窗保持打开。

#### Scenario: 从列头加号新建
- **WHEN** 用户点击「进行中」列头的"+"按钮，在弹窗中输入标题「生成主菜单 UI」并提交
- **THEN** 弹窗关闭，「进行中」列末尾出现标题为「生成主菜单 UI」的卡片

#### Scenario: 弹窗内填写分类信息
- **WHEN** 用户在弹窗中选择分类=功能、优先级=紧急后提交有效标题
- **THEN** 新卡片携带该分类与优先级信息

#### Scenario: 取消不创建
- **WHEN** 用户在弹窗中输入内容后点击取消（或按 Esc）
- **THEN** 弹窗关闭，看板不产生任何新卡片

## MODIFIED Requirements

### Requirement: 看板阶段

任务看板必须展示六个固定阶段列，顺序为：待规划（backlog）、队列（queue）、进行中（in_progress）、AI 审核（ai_review）、人工审核（human_review）、完成（done），与 Autocode 看板的列序一致。列内卡片按加入该列的先后顺序排列。每张卡片显示标题；有备注时显示备注；携带分类元数据时按 Autocode 规则显示徽章——分类、复杂度有值即显示，优先级仅高/紧急显示，影响仅高影响/关键影响显示。每列头必须以区别性配色标识阶段（backlog 中性、queue 蓝、in_progress 信息色、ai_review 琥珀、human_review 紫、done 绿）。列或看板为空时必须显示空态提示而非空白区域。

应用升级时若本地存有旧三阶段（待办/进行中/已完成）数据，必须自动映射到新阶段（待办→待规划、进行中→进行中、已完成→完成），不得丢失或拒载任何卡片。

#### Scenario: 六列全部可见
- **WHEN** 用户打开任务看板
- **THEN** 看板从左到右依次展示 待规划、队列、进行中、AI 审核、人工审核、完成 六列

#### Scenario: 首次打开显示空看板
- **WHEN** 当前工作区从未创建过任务卡片时打开看板
- **THEN** 六列全部可见，各列显示空态提示，页面不报错

#### Scenario: 卡片内容呈现
- **WHEN** 一张卡片标题为「生成主菜单 UI」、备注为「参考 3 个候选方案」、分类为「功能」、优先级为「紧急」
- **THEN** 该卡片显示标题、备注，以及「功能」「紧急」两枚徽章

#### Scenario: 低优先级不显示徽章
- **WHEN** 一张卡片的优先级为「低」、影响为「低影响」
- **THEN** 该卡片不显示优先级与影响徽章

#### Scenario: 旧三阶段数据迁移
- **WHEN** 本地存储中存在 v1 版本数据：待办列有卡片 A、进行中列有卡片 B、已完成列有卡片 C
- **THEN** 升级后打开看板，A 位于「待规划」、B 位于「进行中」、C 位于「完成」，三张卡片均无丢失

### Requirement: 卡片生命周期

用户必须能够通过所在列的新建弹窗创建卡片（提交后出现在该列末尾），必须能够通过编辑弹窗修改卡片的标题、备注与分类元数据（打开时预填当前值），必须能够删除卡片。新建与编辑时标题为空白（仅空白字符）的提交必须被拒绝。列底不再提供内联输入框。

#### Scenario: 在待办列新建卡片
- **WHEN** 用户在「待规划」列的新建弹窗中输入「生成主菜单 UI」并提交
- **THEN** 「待规划」列末尾出现标题为「生成主菜单 UI」的新卡片

#### Scenario: 空白标题被拒绝
- **WHEN** 用户在弹窗中提交仅含空白字符的标题
- **THEN** 不创建（或保存）任何卡片，弹窗保持打开等待修正

#### Scenario: 编辑预填并保存
- **WHEN** 用户对一张标题「旧标题」、备注「旧备注」、分类「功能」的卡片打开编辑弹窗，将其改为「新标题」「新备注」、分类「缺陷修复」并保存
- **THEN** 卡片以新标题、新备注与「缺陷修复」徽章呈现

#### Scenario: 删除卡片
- **WHEN** 用户删除一张卡片
- **THEN** 该卡片从看板消失，且不再计入任何徽标或统计
