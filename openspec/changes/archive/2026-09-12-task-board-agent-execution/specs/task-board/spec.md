## REMOVED Requirements

### Requirement: 发送到智能终端

- **Reason**: 看板任务改为由 agent 在队列中自主执行（Autocode 流程），不再经智能终端中转；用户手动复制提示词的方式被「队列 → 执行 → AI 审核 → 人工审核」取代。
- **Migration**: 「发送到智能终端」卡片操作与对应跨视图事件删除；需要 agent 处理任务时，把卡片放入「队列」列（或对人工审核中的失败卡片点「重新执行」），运行器会自动执行。

## ADDED Requirements

### Requirement: 任务执行队列

看板必须提供任务执行队列：「队列」列中的任务由运行器按入队顺序自动拾取执行，无需用户逐个手动触发。同时执行的任务数必须受并行执行数限制（可在 1–4 之间调整，默认 1，设置持久化）。执行中的卡片必须显示「执行中」标记并提供「停止」操作；停止后该任务按失败处理（标注「手动停止」，落「人工审核」列）。

#### Scenario: 队列任务自动执行
- **WHEN** 「队列」列有 2 张卡片且当前没有任务在执行
- **THEN** 运行器自动拾取第一张执行，该卡片状态变为「进行中」并显示执行中标记

#### Scenario: 并行数限制
- **WHEN** 并行执行数为 1 且已有 1 个任务在执行，「队列」列还有 2 张卡片
- **THEN** 其余卡片保持在「队列」列等待，直到执行中的任务结束

#### Scenario: 停止执行中的任务
- **WHEN** 用户对一个执行中的任务点击「停止」
- **THEN** 该任务停止执行，标注失败原因「手动停止」，卡片落入「人工审核」列

### Requirement: 执行阶段与自动流转

任务执行必须由 agent 在当前工作区内直接完成（提示词包含任务标题、描述与分类信息），不经过聊天会话。执行完成后运行器必须自动发起一次 AI 审核（在工作区内核对任务是否完成）；审核通过的任务进入「人工审核」列并标记「待人工审核」，审核不通过或执行异常的任务同样进入「人工审核」列并标注失败原因。「人工审核」列的卡片必须提供「通过」（状态变为「完成」，标记「已完成」）与「重新执行」（回到「队列」列重新排队）操作。应用重启时，执行中的任务必须回退到「队列」列重新排队。

#### Scenario: 执行完成后进入人工审核
- **WHEN** 一个任务被拾取执行且 agent 完成工作、AI 审核通过
- **THEN** 卡片依次经过「进行中」「AI 审核」后落入「人工审核」列，显示「待人工审核」标记

#### Scenario: AI 审核不通过
- **WHEN** agent 执行结束但 AI 审核判定任务未完成
- **THEN** 卡片落入「人工审核」列并显示失败原因

#### Scenario: 人工通过验收
- **WHEN** 用户对「人工审核」列的一张卡片点击「通过」
- **THEN** 卡片状态变为「完成」，显示「已完成」标记

#### Scenario: 重新执行
- **WHEN** 用户对「人工审核」列的一张卡片点击「重新执行」
- **THEN** 卡片回到「队列」列末尾，运行器按队列规则重新拾取执行

#### Scenario: 重启后恢复
- **WHEN** 应用重启时有任务处于执行中状态
- **THEN** 该任务回退到「队列」列重新排队，不丢失、不悬挂在执行中状态
