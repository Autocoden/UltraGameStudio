## MODIFIED Requirements

### Requirement: 看板阶段

任务看板必须展示六个固定阶段列，顺序为：待规划（backlog）、队列（queue）、进行中（in_progress）、AI 审核（ai_review）、人工审核（human_review）、完成（done），与 Autocode 看板的列序一致。列内卡片按加入该列的先后顺序排列。每张卡片显示标题；有备注时显示备注。每列头必须以区别性配色标识阶段（backlog 中性、queue 蓝、in_progress 信息色、ai_review 琥珀、human_review 紫、done 绿）。列或看板为空时必须显示空态提示而非空白区域。

应用升级时若本地存有旧三阶段（待办/进行中/已完成）数据，必须自动映射到新阶段（待办→待规划、进行中→进行中、已完成→完成），不得丢失或拒载任何卡片。

#### Scenario: 六列全部可见
- **WHEN** 用户打开任务看板
- **THEN** 看板从左到右依次展示 待规划、队列、进行中、AI 审核、人工审核、完成 六列

#### Scenario: 首次打开显示空看板
- **WHEN** 当前工作区从未创建过任务卡片时打开看板
- **THEN** 六列全部可见，各列显示空态提示，页面不报错

#### Scenario: 卡片内容呈现
- **WHEN** 一张卡片标题为「生成主菜单 UI」且备注为「参考 3 个候选方案」
- **THEN** 该卡片同时显示标题与备注文本

#### Scenario: 旧三阶段数据迁移
- **WHEN** 本地存储中存在 v1 版本数据：待办列有卡片 A、进行中列有卡片 B、已完成列有卡片 C
- **THEN** 升级后打开看板，A 位于「待规划」、B 位于「进行中」、C 位于「完成」，三张卡片均无丢失

### Requirement: 列间移动

用户必须能够把卡片在六个阶段之间按列序移动（待规划 → 队列 → 进行中 → AI 审核 → 人工审核 → 完成）：支持把卡片拖拽到目标列，也支持不依赖拖拽的按钮方式（上一阶段/下一阶段）。卡片首次进入「完成」时记录完成时间并在卡片上展示；移出「完成」后清除完成时间。

#### Scenario: 拖拽移动
- **WHEN** 用户把「待规划」列的一张卡片拖到「进行中」列
- **THEN** 卡片从「待规划」消失并出现在「进行中」末尾，入口徽标随之 +1

#### Scenario: 按钮移动
- **WHEN** 用户连续点击一张卡片上的「下一阶段」按钮
- **THEN** 卡片沿 待规划 → 队列 → 进行中 → AI 审核 → 人工审核 → 完成 逐列右移；到达「完成」后按钮不再产生变化

#### Scenario: 完成时间展示与清除
- **WHEN** 卡片被移动到「完成」后再移回「人工审核」
- **THEN** 进入「完成」时卡片显示完成时间，移回后不再显示
